## 🔧 Manual Deploy (Using CLI)

### Prerequisites
```bash
# Install CLIs
npm install -g @railway/cli vercel

# Or use the automated script
./deploy.sh
```

### Deploy Backend (Railway)
```bash
cd /workspaces/MVP-EDIT/backend
railway login
railway init
railway up

# Add PostgreSQL
railway add --database postgres

# Set environment variables in Railway dashboard:
# - JWT_SECRET (generate random)
# - JWT_REFRESH_SECRET (generate random)
# - FRONTEND_URL (your Vercel URL)
```

### Deploy Frontend (Vercel)
```bash
cd /workspaces/MVP-EDIT/transparent-treats-main
vercel login
vercel --prod

# Set environment variable in Vercel:
# VITE_API_URL = your Railway backend URL
```

## 🐛 Troubleshooting

### "Build failed" on Railway
```bash
# Test build locally first
cd /workspaces/MVP-EDIT/backend
npm install && npm run build
```

### "Environment variable missing" on Vercel
1. Go to Vercel dashboard
2. Settings → Environment Variables
3. Add: `VITE_API_URL = https://your-backend.railway.app`
4. Redeploy

### "Cannot connect to database"
1. Check Railway PostgreSQL is running
2. Verify DATABASE_URL is set
3. Run migrations: `railway run npm run db:migrate`

### "CORS error" when accessing API
1. Check FRONTEND_URL in Railway matches Vercel URL
2. Should not have trailing slash
3. Restart backend after changing
